fitcheck⇄ system map
One engine, run two directions: the evidence you've built ↔ the roles you want.

The whole solution on one page. Discovery is delegated to career-ops; fitcheck is the evidence + evaluation layer that turns a job description into the exact, graded, honestly-rendered projection of your record. Read it top to bottom, the way a run flows.

score(experience, target) The atomic operation underneath everything. Hold experience fixed and search targets, that's Scout (discovery). Hold a target fixed and search your record, that's Curate. fitcheck builds the second direction and grades it.

Why two gates

Selection and rendering fail in different ways, so each has its own judge

Picking the right experience and writing it well are separate skills. An early version graded only the picks and shipped bullets that read like label-colon fragments. Splitting the evals fixed that.

Where things live

The tool is public; your record never is

Everything is built in the open, but the private career data stays in a separate repo and is never committed to the public one. The public repo holds only the machinery and fictional examples.
